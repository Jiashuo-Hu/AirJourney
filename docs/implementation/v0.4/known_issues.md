# v0.4 限制、缺项与未测项

- 115家是固定重点航司集合，不是全球所有航司。92家图形可用；23家保留完整文字版作为默认标志，名单在public/data/airline-sources/v04-coverage.json的symbolGaps。Spring没有可靠独立矢量资源，仍占位。未把位图包装为SVG，也未臆造图形。
- 原件和组合版有版权/商标及用途限制。官方HTML可获取不等于已逐一证实全部当前用法；具体确认与未核实项见品牌manifest。Wikipedia的non-free/fair-use说明不授予通用再分发许可；WorldVectorLogo未复制文件。公开发布前需逐项复核适用权利，本轮仅本地交付。
- 用户自定义SVG与历史快照仍可能带文字，优先保存其内容；不擅自删改用户资源。内建默认图形不包含公司名称长文字，但部分标志自身为字母/书法图形。
- 原地图偶发零宽错误的确切自然触发条件仍未知。视口、framebuffer和恢复回归不能证明所有硬件和驱动已无问题。地图静态影像精度、极端重叠、千次重复允许适度覆盖的既有限制保持。
- 独立v0.4离线验收为有条件通过，仅覆盖代码、纯测试、构建及交付核对；未执行独立运行交互验收。尚未完成真实跨机器迁移、干净VM、完整卸载矩阵、低端GPU长时、真实触控板和Windows实际DPI变化。软件显示比例测试不等同实际系统DPI测试。
- 任务栏按钮独立像素及既有固定快捷方式缓存不作已验证结论。检查使用新安装路径的PE和运行窗口图标，不能替代所有Explorer缓存状态。
- 用户要求不占用其桌面后，最终程序回归使用隐藏窗口；不再做前台操作或原生最小化/恢复。先前候选的可见窗口观察不能等同最终包完整前台视觉验收。
- 最终后台悬浮测试从地图已注册事件入口注入坐标，调用真实WebGL命中逻辑；原生鼠标事件接线、实体鼠标和触控板在最终包未重新实测。
- 安装包未签名；构建仍有较大前端chunk提示。普通使用不联网，重新安装开发依赖可能需要网络。机场、航司源目录可能有缺项/历史条目，不是航班真实性或运行状态权威服务。
