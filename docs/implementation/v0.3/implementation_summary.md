# AirJourney v0.3 本地交付

日期：2026-10-15；产品 v0.3，工程 0.3.0。依据本轮用户指令与17号范围；延续 Electron/React/TypeScript/Cesium/SQLite、英语界面与本地使用。没有 GitHub 推送、PR、Release 或产物上传。旧版本产物和报告保留。

## 重复路线与选择

地图和 Map settings 提供 Thicker by count / Separate lines。可选 settings.repeatRoutes 使用原 schema 1，旧数据缺该字段时按加粗模式呈现，只有用户操作时保存新偏好；设置、重启及完整备份均保留。

同一机场对按无向组统计，但不改变航班方向。分组键包括已保存的机场标识及经纬度，避免不同历史快照被错误画成同一路线。加粗线宽为基础线宽加 1.5×log2(次数)，选中另加2px，最终最多16px。悬停显示机场对记录数，点击可选组内具体航班。往返用相反方向的箭头，列表始终显示原方向。

分开模式以 WGS84 最短测地线为中心，按固定规范方向计算法线偏移，反向航班按自己的实际方向绘制同一条偏移曲线。奇数保留中线，其余成对；偶数全部成对。偏移沿 sin(πt) 从两端0平滑展开，半展开宽度不超过航段距离的2.5%或60km。端点和机场点均在原经纬度/4000m示意高度，不改记录、手工距离或WGS84里程。

为大量记录限制几何负担：偶数组最多240个、奇数组最多241个对称显示通道，超出记录按相邻顺序共享通道，允许重叠；每条记录仍在所属通道的选择列表中，组次数完整，选中记录成为该通道代表。零长度航段保留机场点，不伪造非零路线距离。此实现不是实际飞行轨迹，也不是无上限地为每条记录生成实体。

同一 flight-select 再次点击将选中ID设为null；其他记录切换选择。地图材质/线宽/机场描边同步恢复正常，路线保持显示。筛选、已保存航班和编辑草稿不因取消选择改变。

## 统一图标

原标准图案是蓝底白色向右上箭头。将原生成器的几何表达移至唯一源 public/app-logo.svg；所有 PNG/ICO 从此矢量栅格化，不再另画一份或使用字体箭头。包含512px透明PNG、16/20/24/32/40/48/64/128/256px资源和多尺寸ICO。

窗口使用同源PNG、应用内与favicon使用SVG、NSIS与程序PE资源使用同源ICO；启用可执行文件资源编辑，显式 app.setAppUserModelId(local.airjourney.app)。无证书，仍未签名。通过实际安装程序、新安装路径的PE直接图标提取和运行窗口WM_GETICON检查，避免以Explorer缓存缩略图作证。任务栏接收同一窗口/程序图标；未单独截取系统任务栏按钮像素或验证已有用户固定快捷方式缓存。

## 航司目录与标志

随包目录7761条，来自固定OpenFlights与Wikidata快照，4641条缺两字符代码而保留名称。所有给定代码按[A-Z0-9]{2}整理，无效原值进入审计，不编造代码。独立来源ID作为主键；共享/复用代码不合并，只有明确相同身份/同名同码的资料及人工核对的Qantas/KLM法律名称别名合并。原始快照、处理脚本、摘要、重复与缺项在airlines-global-manifest.json及airline-sources中。

20家常见航司以运营/订票/企业站点核对身份，明确列为checked；来源列停运/注销6050条，未核实1691条。OpenFlights特别警告Active标志不可靠，故其Y不直接视为现役。状态不是实时监管或IATA登记核验；目录也含来源中的铁路等运输主体。提供历史名称字段（例如Finnair原Aero名称）、普通来源别名与代码复用提示。国家地区有296个来源名称写法，不等同296个国家。

航司选择改为代码/名称/别名搜索、A–Z、分页和状态筛选，自定义选择器支持键盘。Library可搜索编辑基准的个人覆盖；新目录不全部写入个人库，不静默改历史航班。个人名称、自定义SVG及明确移除Logo的偏好优先。新航班保存便携SVG快照，完整备份不依赖源目录重下载。

20家航司提供完整SVG，19家另提供独立图形。独立图形按完整闭合轮廓提取、保留变换与复合路径镂空，重新贴合viewBox并留边，不矩形截断。Delta从官方新闻站组合中保留完整三角标与DELTA字样，去除独立NEWS HUB/联盟字样，原件保留。新加坡航空从原件中提取两条完整金色飞鸟轮廓，排除蓝色公司文字及独立长下划线；默认和旧内置组合快照均显示飞鸟，保存内容与人工自定义 SVG 不变，完整组合标志仍在资料库保留。Emirates提取上方完整阿拉伯书法图形，去除下方英文名称；ANA保留蓝色/青色图形，去除ANA文字。两家完整组合版仍保留，旧默认组合快照仅显示替换、不改保存数据；自定义SVG优先。Finnair暂保留文字标。没有把位图包成SVG。

优先检查20家官网/媒体页，再取官方SVG或Wikipedia/Commons矢量；有403等访问限制的品牌只完成文件来源身份核对，不能宣称全部已核准最新。官方/文件页URL、原始逐文件许可描述、日期、转换及缺项在public/logos/airlines/manifest.json。商标和版权归原权利人；Wikipedia的fair-use描述和官网下载链接都不是通用商用/再发布授权。British Airways官方媒体物料限媒体编辑用途，未取得额外许可。详见随包notices/Airline-data-and-brands.txt；此次仅本地识别参考资源交付。
