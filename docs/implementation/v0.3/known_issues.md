# v0.3 缺项与限制

状态补充（2026-10-15）：本地实现交付后已完成[简短独立验收](../../acceptance/20261015-v03-independent/report.md)，限定范围PASS、无阻断问题；用户随后另行授权[仓库同步](../github_sync_v0.3.md)。以下未测项仍保留，不将必要验收等同完整验收。

- 独立验收P3：地图放大到浅色陆地时，右下角Repeated routes白色文案对比度偏低；选择器及功能可用，建议后续加半透明底板。本次文档同步不修改已验证程序。

- 全球航司目录不等于权威或完整现役名录；来源时间混合，代码可复用，OpenFlights Y不证明现役。7761条中4641条缺有效两字符代码；保留原名称，未知状态不推断。包含一些非航空运输主体；没有逐条独立核验7761个机构。
- Logo只覆盖20家，19家有独立图形，绝大多数目录条目使用占位。部分官网访问受限，当前品牌仅有来源页核对；并非全部最新。文字标与不宜拆分的组合完整保留。官方/文件来源的版权商标与用途限制均保留；未取得全球品牌的统一商用/再分发授权，特别注意BA媒体用途限制。
- 分开模式超出240/241条时共享对称通道，可重叠；极短航段的间距在远景可能不足一像素。总数、方向及所有记录仍可选择。零距离记录仅显示重合机场点。偏移只为可视化。
- 取消选择不会自动恢复之前相机取景；保持当前地球视角。选择状态为会话UI状态，模式偏好持久化。
- v0.2原偶发零宽绘制错误没有稳定自然复现条件。既有缓冲区保护和有限重建保留，本次实测不能保证所有GPU/驱动/长时间故障均消失。
- 未单独捕获系统任务栏按钮像素，未验证既有用户固定快捷方式缓存；PE和运行窗口原生图标从新安装路径直接读取，AppUserModelID及同源资源已配置。真实Windows DPI切换、全部屏幕/GPU、低配长时压力、真实触控板、干净VM和完整卸载矩阵未完成。
- 安装包未签名。旧地图地名/影像分辨率与政治边界资源限制继续有效。本轮未做完整第三方独立验收；历史报告不改写为本轮通过。
