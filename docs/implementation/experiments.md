## 失败与调整

1. 本机没有Rust/Cargo/MSVC，vswhere为空，无法完成Tauri原生构建实验。采用工程文档允许评估的同前端Electron壳；明确记录环境原因，不声称Tauri本身不支持离线地球。
2. Cesium 1.133 API需 async fromUrl；按安装依赖代码修正，编译通过。
3. Viewer的Knockout依赖需要字符串执行，与CSP冲突。放宽JS unsafe-eval的方案被自动审批拒绝；改用CesiumWidget，只允许本地WASM编译，JavaScript eval仍拒绝且有实际断言。
4. 原始node模块收集/项目内npm wrapper造成空JSON或挂起；改为可复现的最小桌面app打包目录与有效npm wrapper。
5. 安装截图发现标签部分遮挡，修正独立标签的深度与可见半球判定后重打包，hash改变。截图/自测以最终候选目录为准。

早期 smoke-01/02 的失败证据保留，用于说明问题；早期其他成功目录并非最终安装包的完整验收。最终单项自动结果见 `test_report.md` 和相应 JSON，未执行项没有补填 PASS。
