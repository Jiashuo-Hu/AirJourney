# AirJourney v0.0 实现交付记录

基线：`docs/planning` 的 v0.0；包元数据 0.0.0。未改动需求基线、未升级版本、未公开发布。当前是可安装候选，**不是全部 Must 已通过的正式验收结果**。

## 实际实现

- S0：本地 CesiumWidget、4K/2K Natural Earth II、Inter 和真实 SVG；受限本地协议；生产资源打包。领域实验和实际 Windows 桌面闭环已执行。
- S1：手动航班、不完整信息、重复新 UUID、机场/航司/联盟/机型资料、记录快照、本地 SQLite；固定 IANA 规则、明确 offset、DST 歧义保留、WGS84 GeographicLib 测地距离；人工距离与时长独立。
- S2：英语 Flights/Library/Insights/Settings；左管理右地球；侧栏拖宽/键盘调宽、隐藏恢复、草稿保留；AND 维度 / OR 多选筛选、日期和稳定排序、Recorded 汇总；三维线路、机场、反向/重复线路聚合、同点环线、选择与相机联动。
- S3：四类资料新增/编辑/隐藏/恢复默认，JSON/CSV 预览导入导出；仅以后选择与明确历史快照应用；SVG 拒绝危险/非矢量文件、旧快照内嵌资产保留；标签与四类自定义字段、排序/隐藏、改类型保留旧字段；三主题、单位/日期/时钟/密度、全局与单段线路样式、地图标签/视角记忆；手填与地球选点确认；个人本地全球底图导入。
- S4：SQLite 提交、临时写入/替换、上次数据库保护；回收站/恢复/明确永久删除；便携 ZIP 备份、SHA-256、冲突预览/合并/完整替换、导入前备份；安全 CSV；Sources、离线运行时随安装包提供；安装包与源代码交付。

## 具体未完成 / 未满足

1. FR-11 / AC-12：没有取得并核验适合本地三维叠加的内地标准政治边界数据。官方标准地图服务访问核验超时；没有把社区政治边界或关闭开关冒充合格数据。自然色影像不含政治边界，资料库台湾/香港的地域展示为 China，小型英语标签已提供，但这些不能替代标准边界核验。边界开关明确标为资源不可用。
2. FR-14 / AC-15：真实 Lufthansa、Star Alliance、oneworld SVG 已随包；SkyTeam 的找到文件为非自由 Logo，仅 Wikipedia 特定用途说明，未随包分发。因此“三大联盟 SVG”目标尚缺一项。其他未配 Logo 航司明确使用文字占位，可本地导入。
3. 未进行独立第三 Agent 验收、干净 VM/新 Windows 用户实际断网测试、Iris Xe 基准机全套性能、四档系统 DPI 和屏幕阅读器验证。当前应用层外部请求阻断及空应用缓存测试不等于上述测试已通过。

## 工程差异与边界

Tauri/Rust/MSVC 未能在该环境建立可构建链：没有 Rust/Cargo、没有已安装的 MSVC 工具链（vswhere 返回空）。采用工程文档讨论过的 Electron 备选壳，保留 React/TypeScript、Cesium、SQLite 和完全本地目标。没有声称 Tauri 的 GPU 或协议本身失败；此处是构建环境阻塞。未引入服务器、航班验证、爬虫、真实航迹、账户、遥测或自动更新。

SQLite 内保存一个受 schema 校验的完整 JSON 状态文档，业务筛选在内存中进行；并非 Rust/规范化表服务。源代码、备份和资源结构已记录，1,000 条性能探针有真实证据。若后续要求 Rust 迁移，可复用领域契约和前端；需负责人决定后续版本，当前仍为 v0.0。

参见 `delivery_manifest.json`、`requirements_traceability.csv`、`test_report.md`、`known_issues.md`。安装包最终 hash 以清单为准。
