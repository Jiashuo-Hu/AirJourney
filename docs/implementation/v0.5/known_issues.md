# v0.5 已知限制与未测项

- 后台窗口的DOM、WebGL与截图检查不能替代实际前台视觉。侧栏动画的主观流畅程度、原生鼠标/触控板、真实系统DPI、任务栏旧图标缓存、干净VM、完整卸载和低配长时仍待人工确认；不为测试占用用户桌面。
- 原地图偶发零宽错误的自然触发条件未完全锁定。保留视口/缓冲检查与恢复；受控故障注入通过也不能保证全部GPU/驱动长期无故障。
- 年份是临时筛选，不随重启恢复；所有无出发日期记录在All。Planned只是用户状态，日期早晚不自动更改状态。垃圾箱无成果统计。
- 标识归并依赖记录中已有ID/机场代码或航司名称+代码；缺少共同标识的不同快照无法凭空确认同一实体。同名代码复用不能仅凭代码合并，不编造缺失资料。人工记录可能本来就重复，航班数不自动去重。
- 原有86,242条机场、7,764条航司与115家完整Logo覆盖保持；92家独立图形，23家文字回退，Spring无可靠矢量资源。原有版权商标、品牌核实时点、地图影像及边界限制不变，详见v0.4资源清单和随包声明。
- 地球延后加载并未消除全部大JavaScript块；初始界面块仍含品牌快照与时区资料。性能实测受本机负载和文件缓存影响，不推断其他机器或首次安装结果。
- 安装包未签名。2026-10-17独立后台验收在限定功能范围内通过，独立复跑63项纯测试和12项后台专项；前台自然视觉、原生输入和未执行设备矩阵不推定通过，完整旧版升级及故障注入本轮独立验收未重跑。见../../acceptance/20261017-v05-background/report.md。
