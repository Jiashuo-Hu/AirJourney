# v0.5 体积与性能实测

2026-10-16，十进制MB。v0.4对照使用原交付win-unpacked，ASAR与已测安装版哈希4fad6a60…一致（对应安装包9b2c9ba…）；v0.5为本报告指定最终包。资源覆盖、地图像素与全部Logo原件/组合/图形不变。

| 项目 | v0.4 | v0.5 | 缩减（负值为增加） |
|---|---:|---:|---:|
| 构建目录 | 72.88 MB | 46.63 MB | 36.0% |
| 解包程序 | 408.33 MB | 361.10 MB | 11.6% |
| 安装包 | 121.26 MB | 116.07 MB | 4.3% |
| SQLite运行文件 | 21.71 MB | 0.71 MB | 96.7% |
| 全部JS总量 | 9.51 MB | 9.50 MB | 0.0% |

机场JSON从30,681,757字节无损压缩至4,439,191字节，构建时和交付时逐字节解压核对，全部86,242条保留。SQLite移除从未加载的asm、debug、worker及开发ZIP，保留实际WASM与许可证。地球动态分块降低主入口需解析的代码，但总JS并未显著缩小，仍有大块提示；不声称已彻底解决包体或性能问题。

| 新进程观测中位数 | v0.4 | v0.5 |
|---|---:|---:|
| Flights入口可用 | 936 ms | 492 ms |
| 地球运行且静态瓦片加载 | 1812 ms | 2020 ms |
| PEK选择结果等待 | 20.0 ms | 10.5 ms |

两版各3个新进程、合成夹具相同、固定软件DPR 1，隐藏离屏，顺序执行，文件缓存未控制。搜索计时从输入提交后开始，不能等同完整端到端输入延迟。数据见performance.json，不将单机波动当作跨设备提速保证；压缩增加本地解压工作，地球延后加载也不保证首次地球更快。侧栏CSS过渡按五个暂停时间点核对真实绘制比例，没有用固定延时假定帧完成。隐藏环境观察到帧间隔波动，前台动画流畅度待人工确认，不宣称60FPS。
