# v0.5 本地候选实现

2026-10-16，产品v0.5 / 工程0.5.0，Electron/React/TypeScript/Cesium/SQLite架构不变。无GitHub、PR或Release操作。

首页与Insights共用JourneySummary及纯统计函数，避免重复口径。Recorded是用户标注的已完成记录，不验证是否真的飞行；Planned、Draft分别计数，垃圾箱排除。隐藏地图的记录仍计成果。人工距离含零优先，其他记录使用一次现有地理估算；缺失里程不计入总和并列明数量。重复航班仍各自计数。机场按保存ID或机场标识归并；航司按保存ID、品牌标识或名称+代码归并，不仅凭可能复用的航司代码。往返路线为同组，排行不需有坐标，但必须有两个已知端点标识。

年份选择来自当前非垃圾记录（垃圾箱浏览时来自垃圾记录），包括计划和草稿；按出发地当地日期而非UTC、到达日期或创建日期。无日期只在All。现有过滤与年份相交，共同驱动列表、地图和统计。新增、编辑、删除即时更新；当前年份消失则返回All。浏览年份不写入航班，也不新增schema字段。

Map设置保留本地颜色选择，新增仅重置颜色的按钮。设置通过原有串行持久化和完整备份恢复；单条航线自定义颜色优先。选中路线根据普通颜色明暗选取对比色，提高不透明度并保留线宽和其他路线的淡化，兼容重复路线两种模式。

侧栏保持布局节点，通过宽度过渡收放；隐藏时inert并从无障碍树隐藏。地图循环移除“正尺寸需稳定一帧”的等待，每帧调整有效尺寸，变化时请求渲染；零视口/缓冲和原有恢复机制保留。保持同一地球实例和相机，设置减少动态效果时取消侧栏过渡。

适度优化：统一统计逻辑、地球组件按需分块；机场目录仅改变安装后存储为gzip，启动本地解压恢复完整原JSON，构建时逐字节核对；SQLite仅打包sql-wasm.js、sql-wasm.wasm、包元数据及LICENSE/AUTHORS，剔除未用asm/debug/worker和开发ZIP。全部目录记录、原始与派生SVG、地图级别和像素保持，原始资料仍在源码包。结果见performance.md和test_report.md。
