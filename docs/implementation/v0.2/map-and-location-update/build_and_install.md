# 当前 v0.2 更新的构建、安装与备份

产品版本仍为 v0.2，工程版本 0.2.0。当前安装包为 `release/v0.2/AirJourney-v0.2-x64-setup.exe`，当前源码包为同目录 `AirJourney-v0.2-source.zip`。外置 `SHA256SUMS.txt` 给出两个产物的 SHA-256；`package-verification.json` 记录安装后 ASAR、构建文件与源码包逐文件一致性检查。更新前的初始 v0.2 产物保留在 `before-map-location-update`，不作为当前安装包。

## 安装

安装包适用于 Windows x64，未签名。关闭旧应用，建议先在 Settings 导出完整 `.airjourney` 备份，再运行当前安装包。正常安装使用个人本地数据，不需要联网；本次使用隔离目录实际静默安装，退出码 0，并直接运行该目录的 AirJourney.exe 完成回归。没有完成干净虚拟机、完整升级卸载或所有 GPU/驱动矩阵。

## 备份与恢复

使用 Settings 的完整备份导出、恢复预览和确认恢复入口，备份包含航班、个人资料、偏好和 SVG。恢复会替换当前个人数据，应先导出当前内容。旧版本备份中的已保存位置可以原样恢复，恢复后位置仍只读；不能利用资料库导入新增位置或改坐标。已有航班坐标快照不随资料名称修改静默变化。不要在程序运行时直接替换 SQLite 数据文件。

## 重建

在项目根目录，使用 Node.js 与 npm，先 `npm ci`，再 `npm test`、`npm run build`、`npm run package`。包构建依赖 Electron 与 NSIS 工具；准备依赖可能需要网络，生成的应用与安装运行不需要网络。当前本地工具链位于 `.tools`，没有收入源码包。资源数据已随源码提供，不需要重抓。

安装并实测后运行 `node scripts/deliver-v02.mjs` 汇总当前证据、更新追踪表和资源清单、生成源码包及 hash。此脚本要求本轮 final 证据文件存在且通过，并逐文件核对当前构建与安装文件；不是略过测试的打包入口。

专项回归入口为 `node scripts/v02-map-regression.cjs <隔离安装的AirJourney.exe> <证据目录>`；旧库与软件比例回归为 `node scripts/v02-upgrade-display.cjs <exe> <证据目录>`。测试仅使用隔离测试数据，不应指向真实个人数据目录。原始 v0.2 的自由坐标测试已按本轮要求退役，脚本历史存于 `scripts/history`。

## 地图恢复

短暂零尺寸、无效原生绘制缓冲区时暂停该帧；恢复有效后继续。绘制错误或上下文丢失触发地图重建，保留当前视角及航班数据。30 秒最多自动重建两次；仍失败时可用错误面板或地图菜单中的 Restart map，不需要关闭整个应用。该防护已通过故障注入；原自然偶发条件尚未确立，仍需要后续独立验收和设备压力测试。
