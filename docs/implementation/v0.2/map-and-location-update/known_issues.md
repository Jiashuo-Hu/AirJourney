# 当前更新限制

- 原始零宽错误的确切触发条件仍未建立。防护和恢复已经实测，重复操作没有自然停止；不能宣称所有GPU/驱动的间歇性故障已彻底排除。持续驱动故障可能仍需要用户点击Restart map。
- 30秒内最多两次自动重建，避免无限重试；超过时保留数据和恢复入口。
- GPU画面受4百万像素/4096单边上限限制；高DPR大窗口影像可能低于原生DPR，HTML文字保持清晰。未完成低配GPU、长时压力与所有显示配置矩阵。
- 精选18个国家标签，优先级是显示启发式而非官方国家排名；没有全球全部国家地名层。没有三字代码的机场不显示伪造代码。历史已提供的三字代码不保证是有效IATA。
- 机场位置只读，不能新增目录外机场或手工补定位；旧记录坐标保留，不静默迁移。历史备份恢复例外是恢复既有内容，恢复后同样只读；不提供位置编辑工具。
- 真正设备/驱动引发的随机上下文丢失、实际Windows DPI切换、干净VM、完整升级卸载、真实断电与独立重新验收仍未测。
- 旧源数据缺项、坐标准确性无保证、区域影像尺度、跨主页面Library草稿不持久化、未签名等限制仍在。以当前补充范围为准，不沿用旧文档允许手工经纬度输入的描述。
