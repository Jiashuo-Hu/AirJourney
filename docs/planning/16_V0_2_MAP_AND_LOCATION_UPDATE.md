# v0.2 地图与固定机场位置补充范围

用户最新指令优先于旧规划和15号范围中手工定位/自由添加机场位置的要求。产品仍v0.2，工程仍0.2.0；仅本地实现、测试和打包，没有新增发布授权。

- 针对偶发Expected width … actual value was 0及地图停止，检查真实视口/绘制缓冲区、布局与异步时序，增加合理保护和同进程恢复。不把未锁定的触发条件猜成已证明根因。
- 航线默认可见，机场名称默认隐藏；仅悬停航线时显示已提供的三字代码，离开后隐藏，出现/消失平滑。
- 国家名称按屏幕空间避让，缩小时优先保留主要国家，渐显/渐隐。
- 用户不能手工输入、修改或添加机场位置。移除机场位置输入、地球选点、手工新增机场入口；资料导入不能修改坐标/添加未知位置。新选择使用给定机场目录位置。
- 保留既有航班及个人资料，不静默覆盖历史坐标。已有历史坐标和已验证历史备份恢复后保留为只读；未分配的Draft可保存，已有待定位记录可显式选择给定机场替换。非机场资料、自定义字段、标签及航班信息保持可编辑。

旧v0.2实现/独立验收报告保留，最终更新记录位于docs/implementation/v0.2/map-and-location-update。原v0.2交付字节保存在release/v0.2/before-map-location-update。
