# 02 · 功能、业务和质量要求

基线：v0.0。以下记录功能设计目标。本轮验收以07_ACCEPTANCE.md的基本功能标准为准；高级能力和理想指标不足记录为改进项，不以全部Must字样自动否决。

## 1. 功能设计清单

| ID | 功能 | 可验证行为 |
| --- | --- | --- |
| FR-01 | 用户手动创建/查看/编辑/复制航班 | 航班号/日期/时间/航司/机型/里程按用户输入保存，不发起存在性查询 |
| FR-02 | 容忍未知及不完整资料 | 无航班号/航司/机型/完整时间仍可保存；缺坐标保存但标为待定位 |
| FR-03 | 本地机场选择与自由新增/修改 | 搜索代码/名称/城市，可创建无官方代码机场或地点并手动填写坐标 |
| FR-04 | 本地航司、联盟、机型管理 | 新增/改名/别名/隐藏/恢复默认，本地导入导出；自定义联盟与人工归属 |
| FR-05 | 个人标签与自定义字段 | 建立文本/数字/日期/选择型字段、编辑/排序/隐藏，筛选标签；用户数据备份保留 |
| FR-06 | 时间录入与有限本地计算 | 两端当地时间可选，IANA 或明确 UTC offset；已知才计算 UTC/时长，异常保留并标注 |
| FR-07 | 距离录入与地理估算 | 人工距离/原单位/来源文字保留；有坐标给自动距离，切单位不改原输入 |
| FR-08 | 搜索、筛选、排序与基础汇总 | 航司/机场/日期/状态/标签筛选；列表、地图、汇总一致，未知值不被当 0 |
| FR-09 | 本地三维地球 | 断网首次启动可旋转缩放，自然色海陆/地形晕渲、英语地名，本地资源加载 |
| FR-10 | 自动绘制示意线路与机场点 | 只用选定坐标生成；不下载航路；跨日期变更线/重复线可用；列表地图联动 |
| FR-11 | 地图标签与现有图层开关 | 检查地名/机场标签与已有图层的显示开关；未提供图层的情况如实说明 |
| FR-12 | 侧栏与编辑入口 | 左管理右地球，宽度可调、隐藏可恢复，表单草稿/选择不丢失 |
| FR-13 | 英语界面与精致主题 | 默认文字/错误/无障碍 label 英语，浅/深/系统、Inter 及合法字体本地 fallback |
| FR-14 | 本地 SVG Logo 管理 | 起步品牌真矢量、等比例；用户导入/替换/移除，缺失有占位且可继续使用 |
| FR-15 | 外观和地图样式定制 | 强调色、日期/单位、线路样式、标签/现有图层、起始视角、单段颜色；即时预览与恢复默认 |
| FR-16 | 本地数据持久化与资源改动策略 | 应用重启保留记录、资料/资产/设置；编辑资料须显式决定影响现有记录 |
| FR-17 | 完整备份恢复与导出 | 便携备份含自定义 SVG/资料/字段/设置；CSV 可读导出，本地导入预览/去重/冲突 |
| FR-18 | 删除、回收站和恢复 | 航班可恢复/明确永久删除；引用中的资料可隐藏而不会破坏旧记录 |
| FR-19 | 无网络依赖的正常使用 | 不配置地图 token/账户；不请求在线航班、CDN 字体、在线地图或自动更新 |
| FR-20 | 设置、资料入口与资源信息 | Library/Appearance/Map/Data 入口可见；来源/版本/本地数据位置和限制可查 |

## 2. 字段与未知值

| 字段 | 保存要求 | 规则 |
| --- | --- | --- |
| ID、创建/更新时间 | 系统自动 | UUID/UTC，不以航班号为唯一键 |
| Departure / Arrival | 正常记录需两端名称或实体 | 未定位可先保存；Draft 可更少，显示缺项 |
| Airport ID 与坐标 | 可未知 | WGS84，经度 [-180,180]、纬度 [-90,90]；非法数值不进入地理模型 |
| Airline | 可未知/自定义 | 名称和可选 IATA/ICAO；标准标识与用户标签区分 |
| Flight number | 可未知 | 保存原文本，不请求互联网，不限制为仅数字或当前在营航司前缀 |
| 两端日期、时间 | 各自可未知 | Unknown / Date only / Date and time；不伪造补零时刻 |
| 两端时区 | 可未知 | 建议 IANA；可指定 UTC offset；缺失不使用系统时区猜测 |
| UTC、duration | 可推导 | 条件满足且无歧义/矛盾才生成；不完整/未确认则 null |
| Aircraft | 可 Unknown/自定义 | 型号、家族和标准代码均可选，不强制精确子型 |
| Recorded distance | 可未知 | ≥0；用户输入和单位保留，与计算距离独立 |
| Calculated distance | 可推导 | 双端坐标已知时计算；同点为 0；不声称真实航程 |
| Status | 默认 Recorded | Recorded / Planned / Draft，用户自行指定 |
| Alliance label | 参考默认/用户覆盖/未知 | 可 None；不自动核查历史会员 |
| Tags / Notes / custom fields | 可选 | 允许任意语言，备注纯文本，原内容正确保存和展示 |
| Route visibility / color | 可选覆盖 | 不删除数据，只改变显示；记录样式优先于全局 |
| 快照与派生 provenance | 系统 | 用户输入、目录默认、人工覆盖、计算值分别标识 |

## 3. 业务规则

- BR-01：航班真实信息来源是用户，不校验航班号存在、时间是否匹配、实际轨迹或航司历史真实性；无外部查询成功前置条件。
- BR-02：允许未来日期、日期不详、自定义实体与重复内容。重复仅提示，不建立“同航班号只能一次”约束；复制为新记录生成新 UUID。
- BR-03：绘图只依赖两端有效坐标。任一端缺定位就保留记录、显示 Needs location，地图摘要单独报告已显示/待定位/手动隐藏数量，不虚构坐标或默放 (0,0)。合法 (0,0) 本身可以使用。
- BR-04：未知日期/时刻/时区均保存 null 及精度状态；不补成午夜，不使用用户电脑时区代替机场时区。输入非法格式需修正，但可清空该项后保存。
- BR-05：完整当地时间转换使用固定 IANA 规则或用户指定 offset。DST 缺失/重复及到达 UTC 不晚于出发时给出提示；用户可保存原输入为 Time needs review，此时不输出计算时长。选明 offset/修正后恢复计算。
- BR-06：只要坐标有效，时间未核对也可以绘图。飞行时长由有效 UTC 差得出；用户可单独填 Duration override，明确显示 Manual duration，保留计算值而不覆盖。
- BR-07：地理距离采用稳定 WGS84 椭球测地算法；视觉拱高不参与距离。同机场/同坐标显示环线符号与 0 估算距离；没有真实轨迹则始终标 Route illustration。
- BR-08：人工距离优先用于 Recorded 汇总，否则采用地理估算；1 mile=1609.344 m。未知项不当 0，统计显示已纳入条数、未知条数与估算项数。没有坐标但有人工距离照样纳入距离汇总。
- BR-09：联盟以本地建议值和用户覆盖为准；None、Unknown、Custom 分开。不强制飞行时历史关系。用户覆盖不会被起步资料或以后本地导入覆盖。
- BR-10：基础资源与用户覆盖分层。资料更改默认只对以后选用生效；若应用到现有记录，预览受影响 ID 和字段，由用户确认。更新机场坐标时重算几何/距离，保留人工距离；更新时区时提示复核时间。仅本地变更，不向网络反查。
- BR-11：搜索维度之间 AND，维度内多选 OR；默认出发日期降序，无日期列于末尾，同日已知时间先按可比较 UTC，再当地时间和 ID 稳定排序。年份取出发当地日期；未知日期有 Undated 分组。
- BR-12：多次飞同线路可聚合，航段数量按记录计。唯一线路为无方向端点 ID 对；详情/箭头保留方向。同坐标不同地点不合并实体，视觉重叠可弹出列表。
- BR-13：全记录筛选可含三种状态；累计已乘坐汇总基于筛选内 Recorded，不把 Planned/Draft 当已飞。机场/航司/机型 Unknown 不计唯一值，显示缺失计数；区域数量统计暂不做。
- BR-14：侧栏隐藏、筛选、取消编辑或外观恢复不删数据。筛掉选中项时清空该项选择；编辑中的草稿保持并提示。删除进回收站，不自动定期永久清理；永久删除由用户明确触发。
- BR-15：导入/批量套用为事务，先预览；同 UUID 完全相同跳过，内容不同由用户选保留/替换；相似不同 UUID 可同时存在。不主动合并用户不同自定义实体。不支持版本/非法资源拒绝且不改原库。

## 4. 质量要求

| ID | 级别 | 要求与使用条件 |
| --- | --- | --- |
| NFR-01 | 功能 | 本地资源支持日常操作，不需要查询在线航班；本轮不做通信审计 |
| NFR-02 | 功能 | 正常保存、重启和导入恢复不丢记录；失败时有说明，不误报保存成功 |
| NFR-03 | 功能 | 用户原始字段、未知状态和人工覆盖保存/恢复一致，不被自动猜测值覆盖 |
| NFR-04 | Should | Win11 x64/16GB/SSD/Iris Xe 同级/1080p，1000 航段：本地可操作列表 ≤3秒、搜索 P95≤150ms、保存刷新 P95≤500ms、交互中位 FPS≥30；实测并记录差异 |
| NFR-05 | 功能/改进 | 当前设备主要操作可达、界面清楚；全DPI、屏幕阅读器和精细对比度矩阵作为补充检查 |
| NFR-06 | 功能 | 默认英语，字体和已有Logo正常本地显示；缺少某个标志允许占位，不阻碍录入 |
| NFR-07 | 功能/改进 | 当前Windows设备可启动/安装现有交付；不同设备、干净VM与升级卸载完整矩阵作为补充检查 |
| NFR-08 | 功能 | 核对构建/测试、源码和交付文件；正常备份往返保留个人内容；自测和独立验收结论区分 |

容量建议：10000 条可检索/备份且不丢记录，地图可聚合；包体目标与默认地图纹理大小经实验确定，不凭空承诺固定 MB。所有 Should 未达项如实报告，不能引入云服务解决后宣称离线通过。
