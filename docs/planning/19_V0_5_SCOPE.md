# v0.5 实现范围

2026-10-16，产品v0.5、工程0.5.0。以当前v0.4为基础，保持英语、本地使用、schema 1及已有资料，不恢复机场新增或编辑。本轮仅本地构建、测试及交付，无GitHub、PR、Release或上传授权。

- 首页紧凑统计已完成航班数、里程、去重机场/航司及最常飞路线。Recorded按已完成统计，Planned与Draft单独显示，垃圾箱不计成果。人工距离（含零）优先，否则仅取一次现有地理估算；明确缺失和估算数量。
- All及已有出发地当地日期年份倒序选择；列表、地图与统计使用同一筛选结果，和搜索/状态/航司/机场/标签/日期条件相交。无日期只在All。删除不再存在的年份时回到All；年份为临时浏览状态，不改记录。
- 默认路线颜色有直观选择及单独重置入口，即时、持久化、备份恢复；本条路线颜色覆盖仍优先，选中采用有对比的高亮。
- 侧栏宽度连续过渡；每个正尺寸帧都同步调整framebuffer与投影，不等候尺寸稳定，不重建地球、重设相机或改变选中。快速反向切换与窗口缩放也须检查，尊重减少动态效果设置。
- 合并统计逻辑，延后加载地球，机场目录无损压缩，生产SQLite只带实际使用的WASM构建及声明。保留全部机场、航司、原SVG/组合版、地图像素和字体资源，记录实际体积及性能比较，不承诺所有设备提速。

测试不操作系统鼠标键盘、不显示或聚焦原生窗口，只使用隐藏离屏程序、CDP和隔离合成资料。真实前台视觉、原生输入、真实DPI及设备矩阵如未执行，明确待人工确认。
