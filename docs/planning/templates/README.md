# 当前v0.0验收模板

本轮以07_ACCEPTANCE.md的基本功能标准为准。Functional表示功能检查，不等于所有子项都必须完美才通过；Improvement表示补充与改进。真实严重度按是否影响基本闭环判断。

requirements_traceability.csv保留43条设计要求和当前AC对应关系；acceptance_results.csv预置24条用例，NOT RUN只是模板初始状态。复制到新验收目录后填写，勿覆盖已有报告或原证据。

acceptance_report.md用于结论、覆盖、缺陷和后续建议。experiment_report.md/experiment_results.csv用于补充功能探查。asset_registry.csv/resource_manifest.csv只辅助识别实际资源和产物，不开展专项审查。

模板不是测试完成证明，版本仍为v0.0。报告应区分核心缺陷、非阻断不足、优化建议以及未测项目。
