# v0.3 实现范围

日期：2026-10-15，依据负责人本轮指令；产品 v0.3，工程 0.3.0，延续 Electron/React/TypeScript/Cesium/SQLite 和英语、本地使用。仅本地实现、测试、打包，没有 GitHub 授权。

- 重复机场对提供加粗/分开模式，保存选择。往返合组且方向不丢失；奇数居中、成对对称，偶数全部成对，端点固定，小幅展开，大量记录允许重叠。显示偏移不改变记录或里程，地图/列表继续联动。
- 同一现有标准 Logo 生成应用、窗口、任务栏和界面资源，实际检查打包可执行文件图标，不把快捷方式缓存当作资源一致性的证据。
- 全球航司静态目录，代码允许数字；保留无代码、历史、停运、别名、重复代码，不把代码当唯一ID，不推断未知状态。支持代码/名称搜索与字母浏览，保留个人覆盖和历史快照。
- 获取可靠 SVG，优先核对官方品牌，再参考公开矢量来源。尽可能提供独立图形及组合版；可合理拆分时记录做法、保留原件；不裁断/扭曲/以位图冒充矢量。缺项明确占位，记录来源、日期、条件、核对边界，不宣称全量最新。
- 点击同一航班取消选择，其他航班切换；同步清除列表/地图高亮，不改变数据/筛选或影响编辑。
- 验证奇偶/大量重复、持久化、图标、航司/Logo、选择、旧数据、备份和实际安装程序，交付安装包、源码包、hash、简短报告及缺项。
