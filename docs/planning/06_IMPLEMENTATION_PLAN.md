# 06 · 软件实现与交付步骤

基线：v0.0 · 目标顺序：离线可用 → 手动录入闭环 → 自定义 → 视觉细节 → 稳定交付。

不在本计划承诺固定工期；软件编码和界面迭代按阶段推进，少量资源获取并行。完成起步资源即可开发，不等全球航司/机场全集。

## S0 · 本地技术实验

按 10_EXPERIMENTS.md 验证安装包中的本地地球、SVG、字体、时间未知态、资源打包和断网首次启动。采用小型合成航班，不联网获取“真实样本”。

交付：experiments.md、实际包体/资源尺寸/启动与渲染指标、1 组 UI 方向图、离线网络审计记录、轻量地图选择和清晰尺度说明。

准入：离线地球与本地数据可行即可推进；以已有本地资源先形成闭环，不因目录覆盖有限中止工作。技术栈调整只围绕离线本地目标。

## S1 · 记录与资料核心

建立本地 SQLite、Flight/TimeSpec/快照、自定义实体、用户覆盖层；本地搜索、CRUD/duplicate、未知值、简单日期和 offset/IANA、地理距离。

交付：schema/迁移、command 契约、手动样例、自动测试。允许未来/不完整记录，不做航班存在性/运行时刻核验。

通过条件：记录重启保留，自定义航司/机场可用，缺坐标保留为 Needs location，时间不完整不伪造值。

## S2 · 航班界面与路线闭环

完成英语主页面、可调/隐藏侧栏、Add/Edit、搜索/筛选、地图点/线/选择、聚合路线、同机场符号和基本汇总。地球仅读取本地资源。准备必要机场/品牌起步包。

交付：真实截图/录屏和关键状态，列表-地球双向联动验证。首个实用里程碑：断网添加自定义航班 → 路线出现 → 重启仍有。

## S3 · 自由定制与资源管理

完成 Library 四类资料；新增/修改/隐藏/恢复默认；编辑机场坐标和本地选点；SVG 导入/展示/替换；人工联盟归属；资料变更预览/快照应用；标签和自定义字段。

完成 Settings 的主题/强调色/日期/单位/路线样式/标签/现有图层/起始视角，以及每段样式覆盖。所有设置持久化，Reset 只影响相应设置。

交付：定制功能矩阵、资源台账、类型修改/引用资产功能测试、样式高 DPI/对比度检查。

## S4 · 使用细节、备份与安装

完成回收站、便携备份/预览恢复、参考资料本地导入导出、CSV、自定义资产迁移、写入失败处理、错误日志、Source/Notices、离线安装方案。

打磨空状态/未知/待定位/缺 Logo、动画、键盘、DPI/窗口缩放、文字与视觉。硬件兼容/图像分辨率以实测做适配，不临时引入在线地图。

交付：冻结 candidate 安装包/hash、构建/安装说明、资源 manifest、备份恢复说明、自测结果/已知限制、需求执行表。

## S5 · 独立验收与修复

第三个 Agent 按当前基线的 07 文档执行，重点检查断网、完全用户输入、自定义资料和 UI/地图。缺陷交给实现 Agent 修复；新版本提供新 hash，再复测失败与受影响用例。

## 实现阶段文件

统一写 `docs/implementation`：

- implementation_summary.md：实现内容、版本、需求覆盖与差异。
- experiments.md：实验真实结果，列失败和调整。
- architecture.md：本地结构、资源包、领域规则及技术版本。
- resource_manifest.csv、asset_registry.csv：真正随包/用户导入资源与合法使用说明。
- requirements_traceability.csv：当前 v0.0 要求→实现→测试证据。
- build_and_install.md：构建/离线依赖/安装/卸载/数据位置。
- backup_and_restore.md：便携备份、自定义资料/SVG 跨机器恢复和故障应对。
- test_report.md、known_issues.md、screenshots/recordings。

## 完成标准

逐项核对实际功能入口和运行证据；当前v0.0以基本功能闭环为通过目标，高级能力不足列为后续改进。字体、SVG、地图静态文件真实随包，空缓存断网启动可用；手动录入不因外部目录缺失而失败。

Should 性能目标未达要说明实测差距，可优化而不改变产品方向。起步目录规模、未补 Logo 或地图清晰度如实报告，不把它们改写为“所有全球资料已完备”。

范围控制：真实轨迹、全球数据库、自动查询/采集和云服务都不进入首版。照片/OCR/复杂统计等候选也不挤占手动录入、自定义和美化。可逆本地实现自主推进，采购/公开发布需负责人明确授权。
