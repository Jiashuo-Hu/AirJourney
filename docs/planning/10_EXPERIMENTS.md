# 10 · v0.0 功能实验与补充验证

当前已有实现；本文件作为新一轮功能探查清单，不代表这些检查已由本次计划Agent执行。实际结果由验收Agent记录，既有实验见docs/implementation。

| ID | 实验 | 观察重点 |
| --- | --- | --- |
| EX-01 | 打开现有程序并使用本地地球/字体/Logo | 启动与主要界面可用，不要求在线查询航班；不做网络审计 |
| EX-02 | 地球旋转缩放、地名/机场标签与多个端点 | 纹理观感、缩放限度、点线可辨、镜头适配；不审查政治边界 |
| EX-03 | 手动完整/未知/自定义记录保存后补全 | 原输入保持、缺坐标提示、补坐标更新路线、不编造时间 |
| EX-04 | 正常SVG导入/替换及资料修改 | 展示和引用、仅未来/应用已有的区别、重启后保留 |
| EX-05 | 主题/路线样式、标签与个人字段 | 入口、预览、持久化、恢复默认与旧字段值；复杂组合可作改进 |
| EX-06 | 正常备份导出恢复、重复冲突、取消 | 逐字段/资源一致，取消不改原数据，常见格式错误有提示 |
| EX-07 | 常规记录量和窗口操作 | 卡顿、剪裁、侧栏与键盘；性能理想值不作为硬门槛 |
| EX-08 | 现有安装包/运行产物、构建测试 | 当前设备实际可用，说明和文件对应；未有VM标明未测 |

每项记录App标识、设备、输入、操作、预期/实际、证据和问题。使用独立素材，保留真实记录；不执行攻击测试、通信/路径安全检查或资源审查。

发现问题按功能影响分P0–P3，并按07_ACCEPTANCE.md判断基本功能是否可用。技术结构问题只有影响功能或维护时才列具体建议，不要求重构全部工程后才能通过。
