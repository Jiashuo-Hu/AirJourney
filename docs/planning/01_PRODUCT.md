# 01 · 产品需求：我的飞行记录，由我决定

基线：v0.0 · 2026-10-10 · 取代旧稿。

## 1. 用户意图

用户希望用一款漂亮、易用、有自由度的 Windows App 整理自己的飞行旅程。航班信息由用户亲自提供，软件无需从公开互联网寻找或验证每次飞行。价值在于管理、体验与地图表达，而非专业航班数据服务。

典型场景：用户记得自己坐过某个航班，在 Add flight 中输入航班号、起降机场和时间，选择航司，补充机型、里程、备注；保存后在地球上看见一条连接两机场的路线。若某个机场或航司不在目录，直接新增自己的资料并继续，不因目录缺失停下。

## 2. 产品原则

1. 手动输入优先：保留用户原始内容，提供建议但不擅自纠正。
2. 本地自主：正常使用无账号、无 API token、无网络地图订阅；地图/Logo/字体均有本地文件。
3. 易开始、可补全：先保存，再补时间、机型或坐标；不为了生成统计强制填写未知信息。
4. 自定义是首版功能：资料库、品牌、样式和个人字段有真正可操作入口。
5. 地球服务旅程：自然色与地形晕渲强调地理感，路线准确连接用户选定机场；不追求全球街景精度。
6. 资源精简：只提供与本产品相关的静态机场、航司、联盟、机型、SVG 和地图文件；不保存航班时刻表或历史实际运行数据。

## 3. 首版必须交付

| 领域 | 交付结果 |
| --- | --- |
| 航班管理 | 手动增删改、复制为新记录、搜索/筛选；可保存信息不完整的记录 |
| 航班字段 | 起降机场/地点、航班号、两端当地日期时间、航司、机型、距离、备注；用户自行选择和补充 |
| 资料库 | 本地机场/航司/联盟/机型起步资料；新增、修改、隐藏、恢复默认及本地导入导出 |
| 自由补充 | 未知机型、非目录机场、自定义航司、自己填写联盟、标签和自定义字段 |
| 品牌展示 | 起步品牌资源采用真实 SVG，用户可本地导入/替换；缺少 Logo 有清楚、精致的占位 |
| 地球 | 本地自然色和晕渲，连续旋转/缩放，英语地名与实际可用的本地图层 |
| 路线 | 根据机场坐标自动生成示意弧线，地图与列表联动，多次飞同线可展开 |
| 界面 | 左侧管理、右侧地球、可隐藏/调整侧栏，浅/深/系统主题、精致无衬线字体 |
| 定制 | 主题/强调色、单位/日期格式、线路颜色/宽度/透明度、标签与现有图层开关、初始视角 |
| 数据保管 | 本地自动保存、删除可恢复、完整备份/恢复与 CSV 导出 |

本轮按负责人最新指示，以地图可交互、路线正确和基本功能可用为验收目标；现有图层缺口如实记录，不作为地图边界审查任务。

## 4. 首版明确不做

不获取历史实际轨迹，不查询实时航班，不校验航班号是否存在，不匹配航班号与时刻表，不抓取机票网站，不自动计算航司运行准点率，不建立全球历史航班库，不自动推导历史联盟变化，不搭建后台采集平台。

不要求安装后联网初始化，不要求云账号，不要求全球高分辨率地形/卫星瓦片或 3D 建筑。开发时下载依赖与少量静态参考资源允许，但其规模与用途必须清楚。

## 5. 灵活记录与状态

记录可以有完整信息，也可以只有起降地点和记忆中的日期。可选状态 Recorded（默认）、Planned、Draft，由用户选择；未来日期允许，不根据时钟自动改变状态。Planned/Draft 可在地图显示，默认全记录视图可筛选；个人累计已乘坐统计只计算 Recorded 并说明口径。

日期未知、只有日期、只有出发时间或时区不明时允许保存。计算条件不足时显示 Not available，不把缺失时间填成 00:00，不产生假的时长。地图只需要坐标，不依赖完整航班号或时间。

允许同机场起降、重复航班号、虚构用于测试的航班、自定义机型及停运航司。软件只检查数据能否存储/计算/绘图，不审阅用户故事是否真实。

## 6. 主要用户路径

### 添加一条航班

Add flight → 输入航班号（可留空） → 输入/搜索 Departure 和 Arrival → 选择 Airline 或新增 → 填日期时间与可选机型/距离 → Save flight。

机场匹配成功即带入坐标和推荐时区。输入不存在的机场时，显示 Add custom airport；可填坐标当场定位，也可稍后补。保存后侧栏立即显示记录，地图绘制所有已定位线路，未定位记录进入可点击的 Needs location 提示。

### 自己维护资料

Library → Airports / Airlines / Alliances / Aircraft → 搜索实体 → Edit / Add new → 修改名称、代码、坐标、时区或 SVG → 预览 → 保存。机场修改会提示影响哪些航班，用户选择只用于以后记录或应用到现有记录；旧记录不被静默改写。

### 打造自己的视觉

Settings → Appearance / Map → 切换主题、强调色、路线和标签 → 即时预览 → 保存。每段也可设独立颜色；Reset style 恢复视觉设置，不清空航班或资料。

### 备份与迁移

Export backup 生成包含航班、自定义资料、SVG、自定义字段与设置的便携备份包。另一台机器本地导入，无需联系任何网络服务。导入先预览重复/冲突并可取消。

## 7. 实用默认值

Windows 11 x64 优先；单用户；默认 km、24 小时制、英语界面与 Inter。日期格式可切 `DD MMM YYYY` / `YYYY-MM-DD`。起步目录只提供实用范围，具体名单由实现阶段记录，不把某个数量变成新的产品门槛。

标签、自定义字段、资源管理、离线地图为本版真实功能。PDF 报表、照片、OCR、旅行分享、云同步和真实轨迹仅是未来可能扩展，不进入首版验收。

## 8. 成功体验

用户可断网完成新增、自由修改资料、重新打开记录和查看地图；未知信息不会阻止保存；设置能持久保存；地图自然色清晰、航线可辨、侧栏隐藏可恢复；备份后能原样恢复所有个人内容。

一条已定位航班保存后目标 500 ms 内更新列表和线路。1000 条个人记录流畅使用。所有显示差异与缺失有清楚反馈，没有为了“专业”而额外加入的外部数据库门槛。
