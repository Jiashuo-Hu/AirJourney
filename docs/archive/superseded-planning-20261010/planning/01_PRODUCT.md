# 01 · 产品需求与范围

状态：已失效旧稿（未编号） · 2026-10-10 · 状态：计划基线

## 1. 产品定位

AirJourney 是面向个人用户的飞行记录册。用户手动录入已乘坐的每个飞行航段，查看自己去过的机场、使用过的航司和机型，并在地球上感受旅程的地理分布。它不是订票、实时航班追踪或航班运行管理系统。

核心用户故事：我从一张旧机票或自己的记忆中整理航班，选择航空公司和两个机场，填写当地日期时间及机型，立即在地球上看见旅程；之后可以搜索、修订、筛选、备份，并在地图全屏状态回顾旅程。

## 2. 范围与推荐默认值

| 维度 | 初始基线 |
| --- | --- |
| 平台 | Windows 11 x64；ARM64 和 Windows 10 为后续候选，不做 旧稿 硬性承诺 |
| 用户 | 单用户；不要求账号、云服务或登录 |
| 存储 | 本地优先；断网可管理航班，地图在线细节可降级 |
| 界面 | 全英语，默认 24 小时制，日期采用 `10 Oct 2026` 等不歧义形式 |
| 距离 | 默认 km，可切换 miles；计算结果与用户输入距离分别保留 |
| 航班单位 | 一条记录等于一个起降航段；中转旅行分别添加多个航段 |
| 航班性质 | 旧稿 记录已搭乘旅程；预订、取消或计划航班不进入默认完成统计 |
| 地图 | 全球三维地球；近距离需要可辨识海岸线、地形色与机场定位，不要求街道导航或建筑模型 |
| 对照标准 | 航空标识使用 IATA/ICAO；地图呈现使用中国内地适用标准，二者分开管理 |

个人使用不代表航空数据库、地图或字体无授权限制。若未来公开分发或商业化，应重新核验许可、地图审核适用性、品牌使用和分发方式；本次不购买资源、不申请账号、不发布应用。

## 3. 旧稿 必须具备（Must）

- 航班增删改查、搜索筛选，航司、起降机场、两端当地日期时间、机型、距离选择或录入。
- 航司与联盟的状态区分及来源；支持无联盟、未知和历史关系。
- 所有正式支持航司和三大联盟的已核验真矢量 Logo；资产文件随程序本地提供。
- 三维地球的拖动旋转、缩放、恢复总览、机场点与航线；列表和地图双向选择。
- 陆地、海洋、地形色和有效地形数据。仅一张平面截图或单色球体不满足最终要求。
- 中国内地标准下的地图边界、地名和地域分类验证，来源及版本可追溯。
- 可隐藏、调整宽度及恢复侧栏；浅色、深色和系统主题；键盘操作。
- 数据持久化、JSON 完整备份/恢复、CSV 表格导出、错误恢复与安装卸载行为说明。
- 基本统计：航段数、累计记录距离、累计时长、不同机场/航司/机型数；口径固定。

备份、统计、主题等是为个人记录工具补充的推荐 旧稿 要求；用户可调整，不能挤掉最初四项核心功能。

## 4. 后续候选（候选，不作为 旧稿 验收条件）

| 能力 | 意义 | 前置条件 |
| --- | --- | --- |
| 登机牌 OCR、邮件/票据导入 | 减少手动录入 | 单独隐私和准确性设计 |
| 真实飞行轨迹 | 显示实际绕飞与高度 | 获得合法历史轨迹数据及授权 |
| 旅行分组、座位、舱位、照片 | 更完整旅行回忆 | 数据模型扩展及存储管理 |
| 更丰富统计与年度回顾 | 分享旅程 | 地图截图输出授权 |
| 云同步、手机端、多人档案 | 多设备管理 | 账号、加密、冲突解决 |
| 完整离线高分辨率地球 | 旅行途中查看 | 离线数据授权、空间和分发预算 |

## 5. 主要流程

首次打开：展示真实地球与空列表，说明记录保存在本机，按钮 `Add your first flight`。

添加：点击 `Add flight` → 搜索航司 → 搜索两个机场 → 核对当地日期时间和时区 → 选择机型或 Unknown → 查看计算距离并按需输入自己的距离 → 保存 → 列表出现记录、地图显示弧线、统计更新。

回顾：按年份、航司或机场筛选 → 地图显示筛选结果 → 点击航线或机场 → 左侧显示相关航班 → 隐藏侧栏欣赏全地球 → 恢复侧栏继续管理。

修订：编辑记录，若修改机场导致时区变化，要求重新核对当地时间；保存时一次性更新数据、路线与统计。删除需要确认，可在 30 天回收站内恢复。

备份：导出版本化 JSON 文件 → 在空数据库或另一 Windows 用户配置中预览导入 → 查看新增、重复、冲突与错误 → 确认恢复 → 验证原记录内容。

## 6. 成功标准

- 用户能够在约 60–90 秒内添加一条字段齐全的航班；该项为试用目标，速度不是绝对阻断指标。
- 两端时区和跨日显示正确，不因为到达当地时间早于出发而拒绝合法旅程。
- 1000 条航班可检索并在地球流畅回顾；10000 条不丢失数据且有可用降级。
- 实际支持目录中不存在伪造 Logo、代码、联盟关系和“全部实时准确”的无证据承诺。
- 断网或地图失败不会阻断航班管理；重新联网可恢复地球细节。
- 安装包能在没有开发工具的 Windows 11 机器上启动；完整验收按 07 文档执行。

## 7. 产品负责人以后需要决定的事项

付费资源预算、公开发布计划、历史航司深度、全世界航司 Logo 覆盖的投入和是否需要真实轨迹。初始开发采用无账号、本地优先、不承诺付费的默认值；实现 Agent 必须先给出具体覆盖与费用证据，再请求决策。
