# 02 · 系统要求与业务规则

状态：已失效旧稿（未编号） · 所有 FR/NFR 均为 旧稿 Must，除非标记为候选。每条要求必须对应 07 文档中的验收项。

## 1. 功能要求

| ID | 要求 | 可观察结果 |
| --- | --- | --- |
| FR-01 | 添加、读取、编辑单个已搭乘航段 | 保存后重启仍存在，修改同步更新地图和统计 |
| FR-02 | 删除、30 天回收站、恢复、明确永久删除 | 删除后默认列表/地图不显示；恢复内容一致 |
| FR-03 | 标准机场和航司目录，可搜索代码/英语名称/城市 | 显示明确候选，区分城市代码和机场代码，禁止虚构代码 |
| FR-04 | 关联联盟，支持当前/飞行时关系 | 成员、无联盟、未知、暂停及合作伙伴不同显示 |
| FR-05 | 两端日期时间、时区、UTC 转换及飞行时长 | 夏令时重复/缺失时间明确处理 |
| FR-06 | 机型目录及未知/自定义机型 | 不强迫用户猜型号；支持回忆不完整的记录 |
| FR-07 | 自动地理距离、人工记录距离和单位切换 | 不把示意距离称为真实飞行或积分里程 |
| FR-08 | 列表搜索、年份/航司/机场/联盟筛选和排序 | 列表、地图、统计共享同一筛选状态 |
| FR-09 | 三维地球，旋转、缩放、总览及地形 | 从全球连续缩放到机场区域，无固定截图假交互 |
| FR-10 | 所有有效航段航线、机场点和双向选择 | 同线路聚合保留全部记录，多条可选 |
| FR-11 | 中国内地标准的地图表达和英语地名 | 所有启用图层一致，来源/版本/审核信息可查 |
| FR-12 | 可调整、隐藏及恢复侧栏 | 地图实时补满空间，记录选择和表单状态保留 |
| FR-13 | 英语 UI、系统/浅色/深色主题、Inter 字体 | 用户可见默认字符串均为英语，无字体联网依赖 |
| FR-14 | 航司和联盟矢量 Logo | 正式支持目录覆盖 100%，离线显示，200%/300% DPI 清晰 |
| FR-15 | 本地持久化、版本化迁移和灾难恢复 | 数据损坏/升级失败不会静默重建空库 |
| FR-16 | 完整 JSON 备份恢复、CSV 导出 | 往返保留时区、历史快照及人工输入；CSV 可读 |
| FR-17 | 汇总统计和明确口径 | 相同筛选产生可复核数字 |
| FR-18 | 设置与来源信息 | 主题、单位、资源版本、许可证、地图归属和数据目录可见 |

## 2. 航班字段

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 内部记录 ID | 系统生成 | UUID，不使用航班号充当主键 |
| Operating airline | 是 | 实际承运航司；目录 ID 或明确自定义实体 |
| Marketing airline | 否 | 代码共享时可单独记录，不覆盖承运航司 |
| Flight number | 否 | 可保留原始用户文本；规范化只用于检索/重复提示 |
| Departure / Arrival airport | 是 | 目录机场或带坐标和时区的自定义机场；不能仅填城市 |
| Departure / Arrival local datetime | 是 | 两端分别完整年月日和时分，不隐式猜次日 |
| Departure / Arrival time zone | 是 | IANA 时区；默认来自机场核验映射，可明确修正 |
| 两端 UTC / offset | 系统生成 | 必须保留选定时刻对应偏移；转换来源有版本 |
| Time basis | 是，默认 Recorded | Recorded 或 Scheduled；均不得声称来自实时跟踪 |
| Aircraft type | 字段必选，型号可未知 | 选标准型号、Unknown 或标记 Custom |
| Calculated distance | 系统生成 | 两机场 WGS84 地理距离，单位 m，算法版本固定 |
| Recorded distance | 否 | 用户输入并保留原单位、来源说明；大于 0 |
| Notes | 否 | 纯文本，最大 10000 字符，允许任何语言 |
| Source / snapshots | 系统生成 | 数据版本、机场坐标/名称、航司名和联盟来源快照 |
| Created / Updated / Deleted at | 系统生成 | UTC，便于迁移、去重和回收站 |

里程默认指距离。奖励积分或会员里程不混入本字段；如以后增加，使用独立字段。

## 3. 业务规则

- BR-01：一航段对应一个起飞机场和一个实际到达机场。往返两条，中转逐段，备降到实际机场。相同起降机场允许，显示提示并将端点距离记 0，路线用环线符号，不编造航路。
- BR-02：所有时间先按机场当地时间输入，再转换 UTC。保存时 `arrival_utc > departure_utc`；当地日期可能跨日、早于出发当地时间或跨国际日期变更线。
- BR-03：夏令时缺失时间阻止保存并解释；重复时间显示两个 UTC offset 供选择。不依据系统所在时区决定机场时区。无核验机场时区时必须由用户明确选择，不能默用 UTC。
- BR-04：飞行时长等于两 UTC 时刻之差；大于 24 小时给核对提示，用户确认可以保存。不自动减去经停或时区差。
- BR-05：旧稿 已搭乘模式不允许到达 UTC 在当前时刻之后。历史时间精度到分钟；未知时间的日期-only 记录留待后续，当前不伪造时间。
- BR-06：联盟默认按飞行日期查询实际承运航司的历史成员关系；历史证据不足显示 `Unknown at flight date`。详情可另外展示 `Current alliance`。合作伙伴、拟加入与暂停不等同正式会员。
- BR-07：机场/航司可能改名、停运、代码复用。实体 UUID 是身份，代码只是带有效期的标识；历史记录采用保存时快照，目录更新不能追改已存时间、距离和名称。
- BR-08：全程标为 `Route illustration`。弧线展示不等于真实航路、ATC 轨迹或实际飞行高度。视觉拱高不参与距离/时长计算。
- BR-09：计算距离使用 WGS84 椭球最短测地线；显示 km 一位小数，miles 一位小数（1 mile = 1609.344 m）。累计记录距离优先使用人工 Recorded distance，否则使用计算距离，并注明其中估算部分。
- BR-10：同线路可合并显示弧线，但航段数仍按记录条数统计。唯一线路数采用无方向机场对；箭头和选中详情保留飞行方向。
- BR-11：唯一机场数为非删除记录两端机场 ID 的集合；航司数按实际承运实体；机型数排除 Unknown，自定义规范化型号独立计数。累计时长相加，跨年以出发机场当地年份分组。暂不输出国家数统计，以免地域口径误解。
- BR-12：重复提示依据承运航司、起降机场和出发 UTC；不是硬性唯一约束。用户可以确认保留同样内容的独立记录。
- BR-13：多个筛选维度 AND，单一维度内多选 OR。文本搜索涵盖航班号、航司、机场、城市和备注，大小写不敏感。默认按 departure_utc 降序。
- BR-14：选中记录被筛选排除时清空选择并关闭其详情，不悄悄扩大筛选。机场点击显示当前筛选结果内相关记录；弧线点击显示对应组列表。
- BR-15：编辑取消不改变持久化内容；关闭带修改的表单必须提示。数据库写入成功后才显示保存成功；磁盘不足时保留用户草稿。
- BR-16：回收站项目不参与默认地图、搜索和统计。30 天以 deleted_at UTC 计算；超过期限可在下次启动清理，完整备份支持可选包含回收站且明确标记。
- BR-17：自定义航司、机场和机型可记录历史缺失信息，UI 标明 `Custom`。自定义机场经纬度范围有效且时区明确；自定义记录不能被当作已核验标准目录。

## 4. 质量要求与测量条件

NFR-01 数据安全：单次写入/导入为事务；迁移前备份；失败不破坏原库。数据库完整性校验、可恢复副本和人工导出路径有效。

NFR-02 隐私：不默认上传航班/备注；不默认开启遥测。地图网络请求可能暴露 IP、视窗区域和用量，需要英语说明。云地图 token 无法作为桌面包内的绝对秘密，应限定权限和额度。

NFR-03 性能：Windows 11 x64、16 GB RAM、SSD、Intel Iris Xe 同级集显、1920×1080、100% DPI，1000 航段/500 个不同机场为基准。应用冷启动到可操作列表 ≤3 秒（不含安装 WebView2 与地图下载）；本地搜索 P95 ≤150 ms；保存后列表/路线状态更新 P95 ≤500 ms；地球交互中位数 ≥30 FPS；稳定空闲进程树内存 ≤800 MB。目标值待 P0 实测验证；调整必须记录而不能靠改变测试机掩盖。

NFR-04 网络：20 Mbps、100 ms 延迟测试可用地图，正常服务下初次有纹理地球目标 ≤10 秒；15 秒未就绪展示状态与重试，列表可用。断网不得误报数据丢失。

NFR-05 可访问性：键盘可完成录入、编辑、筛选、备份；焦点清晰且无键盘陷阱；正文对比度 ≥4.5:1、可操作控件 ≥3:1。地图的信息有列表等效入口，尊重 Reduce motion。

NFR-06 布局：最小窗口 1024×720；100%、150%、200%、300% DPI 无截断关键操作。系统缩放使可用逻辑尺寸更小时进入滚动/紧凑布局，不能溢出屏幕。侧栏布局详见 03。

NFR-07 发布：安装后无需 Node/Rust 或开发工具；检测和安装 WebView2；签名状态明确，未签名测试包不能称为已签名正式版。卸载默认保留个人数据，有明确清理方式。

NFR-08 容量：10000 航段可加载、搜索、编辑、备份且不崩溃；允许路线聚合和质量降级，但不能遗漏数据库记录。压力测试记录实际帧率/耗时而非宣称与 1000 条相同。

NFR-09 资产与地图：每个随包资源有来源、版本、hash、使用许可和归属要求；正式支持航司 Logo 覆盖与地图来源验证为最终阻断项。

NFR-10 工程：核心计算、持久化和导入具备自动验证；类型检查、lint、构建、安装冒烟和独立验收证据完整。依赖锁定、更新流程可复现。
