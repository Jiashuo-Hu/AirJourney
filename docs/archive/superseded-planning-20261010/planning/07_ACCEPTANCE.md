# 07 · 独立验收计划与用例

状态：已失效旧稿（未编号） · 执行角色：第三个验收 Agent · 当前所有产品用例均为 NOT RUN。

## 1. 验收原则

先检查计划基线、最终需求追踪、实现差异、地图/Logo 台账、安装包 hash、依赖和数据版本，然后在真实 Windows 环境运行。不要根据应用启动截图或实现 Agent 的口头结论判定通过。代码审阅和自动测试可以辅助，不能代替安装/地图/交互实测。

每条结果记录 PASS、FAIL、BLOCKED、NOT RUN 或事先经负责人批准的 WAIVED。地图/Logo 缺证据记 BLOCKED，不记 PASS。用户四项核心要求的豁免必须由负责人显式变更基线。

验收过程中不修改产品代码或原始数据集；问题返还实现 Agent。验收报告本身、独立测试素材和脱敏证据可写入 `docs/acceptance`。每轮 build hash 固定，修复后重建并另开一轮。

## 2. 环境矩阵

- 主环境：Windows 11 x64，16 GB RAM、SSD、Iris Xe 同级集显、1080p；记录具体系统 build、GPU/驱动、WebView2、应用版本与 hash。
- DPI：100/150/200/300%，浅色/深色/系统；至少一组高 DPI 真实机器或明确说明模拟方法。
- 网络：正常 20 Mbps/100 ms、完全断网、供应商拒绝/token 失效、瓦片慢响应。
- 数据：空库、约 20 条边界样例、1000 航段/500 机场、10000 航段压力集。
- 安装：无开发工具的新用户/干净 VM；WebView2 已有/缺失；在线引导与离线部署说明。
- 显卡：至少集显主环境；若能获得独显补测，不能用高端显卡结果替代主环境。

性能记录包括进程树内存，不能只测主进程而忽略 WebView 子进程。初始地图下载与本地启动分开记录。

全部为 Synthetic 测试航班，不是历史真实航班；机型/航司按已核验目录选择即可。时区素材采用 2024 年历史规则，验收 Agent 应以独立固定 tzdb 核对。

## 5. 性能采样

冷启动从启动安装后的应用到列表可操作计时，首次 WebView 安装另记。搜索输入到结果稳定采样 30 次，保存从提交到列表和路线状态同步采样 30 次，按排序样本计算 P95。地球 FPS 在可重复的 60 秒旋转/缩放脚本中采集，并标注加载中与加载完成。空闲 2 分钟后测进程树内存；持续交互 15 分钟观察是否增长失控。

不能使用开发热更新服务器的结果替代 release build，也不能把瓦片全部缓存后的速度称为首次联网加载速度。

## 6. 严重程度与最终结论

- S0：数据损坏/泄露、不可逆丢失、安全严重问题。停止发布。
- S1：核心功能不可用、时间/距离错误、路线遗漏、地图表达/许可阻断、正式目录 Logo 缺失、无法正常安装。阻断完整旧稿范围。
- S2：非核心功能/特定场景缺陷、有明确绕过方法。是否允许候选版本使用由负责人决定；未豁免 Must 不得宣称全量通过。
- S3：轻微视觉、文案或后续优化。

最终结论：PASS / FAIL / BLOCKED / CONDITIONAL。完整 PASS 要求全部 FR、BR、NFR 的相关 Must 用例通过且没有开放 S0/S1；非核心例外有负责人记录的豁免，仍必须明确标注范围。资源证据/测试环境不可获得时用 BLOCKED，不能推定 PASS。
