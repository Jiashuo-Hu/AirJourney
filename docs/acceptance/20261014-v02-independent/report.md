## 阻断与改进

优先处理V02-N02 P1：正常地图在新建近似短航段及后续普通操作中出现width=0的Cesium framebuffer错误，停止绘制；正常重启可恢复。首个错误有完整截图和栈，之后同类操作再次记录同错误；再一次全新重启的三轮切换/保存没有出现，因此是**偶发，确切触发时序未锁定**，不是每条短路线必然失败。列表、保存和导出继续可用，但不能用脚本的数据断言通过掩盖地图已停止。

再处理V02-N01 P2：Library手输坐标未更新位置类型/来源，未来选择仍归于来源机场坐标；新建手工位置也默认标Airport coordinates。需要自动标User location或提示重新确认来源，并保留显式近似选择。

随后优化近邻标签避让/聚合，增加常用运营机场类型筛选，避免闭场/直升机坪结果干扰；现有测试增加页面渲染告警检查与视觉证据审阅，聚合弹层改为条件等待。源坐标质量/覆盖缺项可持续更新，但本轮不要求全量现实核查。
