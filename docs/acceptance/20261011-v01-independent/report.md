## 新问题与建议顺序

先修 **V01-N01 P2：普通设置保存后航线消失，镜头输入后恢复**。两次测试模式复现，再在正常发布模式复现；机场标记/记录不丢，轻微滚动即恢复，所以按当前标准不阻断，但与本版地图体验目标直接相关，应优先处理。它说明现有回归“实体存在/最终截图通过”仍漏掉静止时异步绘制问题，应增加设置/编辑后不移动相机的截图断言。

随后处理 **V01-N02 P3：地图装饰文字在浅色底图低对比**，**V01-N03 P3：资料编辑切类别静默丢草稿**。布局整洁、基本美观，但这两处影响阅读与操作安心感，不宣称整体视觉无瑕疵。

再考虑机场/航司可检索选择、详情直接显示到达时间、Reset适配当前路线和隐藏装饰标题。跨日期UTC顺序的探索观察不记bug：需求BR-11明确优先当地出发日期；建议把Newest/Oldest标明当地出发日期。修改地点名会保留旧代码/坐标，允许字段独立覆盖，可增加“沿用坐标”的提示及清空入口，未据此认定地图计算错误。长期可按具体依赖更新实体、减少不相关设置导致地图重建并拆分重资源包。
